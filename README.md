# 🧰 Skills

记录我在开发和学习过程中总结的 AI Skills。

把反复用到的方法、有效的提问方式和实践经验整理下来，让 AI 更清楚我想怎么做，也让自己少走一些重复的弯路。

## 📚 目前有哪些

| Skill                                                              | 用途                                                                                                 |
| ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| [用开发故事理解技术架构](./explain-project-through-story/SKILL.md) | 从具体业务出发，讲述项目逐步演进的过程，提前认识可能遇到的问题，以及对应的技术分类、解决方案和代价。 |

## 💬 怎么用

让支持读取本地文件的 AI 编程工具阅读对应的 `SKILL.md`，再描述你的项目和目标。例如：

> 请使用 explain-project-through-story，讲一个 Go 团队知识库从第一版到多人使用的开发故事。

如果工具支持安装和调用 Skills，也可以按它的使用方式加载。不同工具的配置方式可能不同。

## 🗂️ 怎么组织

每个 Skill 使用一个独立目录：

```text
skill-name/
├── SKILL.md       # 适用场景与执行方法
└── references/    # 按需读取的示例、分类和补充资料
```

## 🌱 持续更新

希望它们能帮助开发者在动手前想清楚问题，在开发中理解取舍，在完成后讲清楚自己解决了什么。
